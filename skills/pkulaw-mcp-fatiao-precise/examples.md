# 使用示例

## 示例一：已知法规名和条号

### 用户输入

```text
请帮我查《中华人民共和国民法典》第五百七十七条的原文。
```

### 推荐行为

1. 用户已经明确给了法规名和条号。
2. 直接走精准法条查询。
3. 只返回当次命中的条文内容与复核提醒。

### 推荐输出

```markdown
## 命中法规
- 《中华人民共和国民法典》

## 条号
- 第五百七十七条

## 条文正文
- [此处仅列当次返回中的正文]

## 复核提醒
- 结果来自当次精准法条查询返回，使用前仍建议复核时效与适用前提
```

## 示例二：不该用这个 Skill 的情况

### 用户输入

```text
帮我找劳动合同解除相关法律依据。
```

### 推荐行为

这不是精准法条查询，而是法规检索，应转到法规检索 Skill。
