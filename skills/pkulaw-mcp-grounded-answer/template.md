# Grounded Answer Template

在输出法律答复草稿时，优先使用下面的模板。

```markdown
## 问题与适用前提
- 问题：[用户要解决的核心问题]
- 当前前提：[已知事实、法域、时间点]
- 仍待补充：[若有]

## 简要结论
1. [结论 1，避免绝对化措辞]
2. [结论 2]

## 主要依据
- [法规/案例名称]：[与本问题相关的要点]（来源：当次 MCP 返回）
- [法规/案例名称]：[与本问题相关的要点]（来源：当次 MCP 返回）

## 引用核验结果
- 与当次返回一致：
  - [引用A]
- 待人工复核：
  - [引用B + 原因]

## 实务提示
- 可以直接用于沟通的内容：[1-2 句]
- 不宜直接下结论的部分：[1-2 句]

## 链接化版本
- [如已生成 doc-link，则列链接或增强后的文本]

## 使用边界
- 本答复为资料研究与业务支持草稿，不构成正式律师法律意见。
- 对外发送前，请由承办律师或负责人员结合完整事实再次复核。
```

## 使用要求

- 若关键信息不足，先补“问题与适用前提”，再写结论。
- 结论必须和“主要依据”一一对应。
- 没有核验的具体法条，不要写成确定依据。
