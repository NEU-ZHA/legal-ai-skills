# Grounded Answer Examples

## 示例一：给业务的劳动用工答复

### 用户意图

“员工连续两个月绩效不达标，公司能不能直接辞退？帮我整理一个给业务的答复口径。”

### 推荐处理

1. 先补充：
   - 员工所在地
   - 劳动合同类型
   - 绩效制度是否书面公示
   - 是否需要类案
2. 用法规检索 Skill `pkulaw-mcp-law-retrieval` 检索解除劳动合同相关规则。
3. 如需看裁判倾向，再补案例检索 Skill `pkulaw-mcp-case-retrieval`。
4. 草稿里出现具体法条时，用 `citation-validator` 核验。
5. 输出“简要结论 + 主要依据 + 需复核点”的答复草稿。

### 适合的输出风格

- 面向业务：结论先行，术语尽量少
- 明确写出“基于当前已知事实”
- 明确写出“若绩效制度未有效公示，风险会明显上升”

## 示例二：给客户的合同纠纷回复草稿

### 用户意图

“租赁合同到期后房东不退押金，我怎么回复客户？”

### 推荐处理

1. 先补充：
   - 合同签订地/履行地
   - 是否存在违约事实
   - 押金条款原文
   - 是否需要类案支撑
2. 用法规检索 Skill `pkulaw-mcp-law-retrieval` 检索押金返还、违约责任相关规则。
3. 需要类案时，补案例检索 Skill `pkulaw-mcp-case-retrieval`。
4. 输出“问题与适用前提 / 简要结论 / 主要依据 / 实务提示”。
5. 需要转发客户时，再补 `doc-link`。

### 不要这样做

- 不要在事实不清时直接说“可以起诉且一定支持”
- 不要把未核验的条文内容写成确定依据
