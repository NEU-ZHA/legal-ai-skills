# Governance Research Memo Examples

## 示例一：股权转让争议研究

### 用户意图

“帮我研究一下股权转让后，公司拒绝变更登记时一般有哪些规则和案例，准备做个内部备忘。”

### 推荐处理

1. 先问：
   - 公司类型
   - 是否限定地区或近年样本
   - 更关注规则依据还是裁判实践
2. 先拆成规则问题与案例问题，分别用 `law-keyword` 和 `case-keyword` 检索。
3. 定向检索仍有关键缺口时，才用一次 `semantic-nlsql` 补充综合召回。
4. 输出“主要规则线索 / 主要案例线索 / 初步判断 / 待研究问题”。

### 不要这样做

- 不要把综合召回的材料直接堆给用户
- 不要在样本有限时直接下“普遍如此”的结论

## 示例二：董事责任研究备忘

### 用户意图

“客户问董事在关联交易决策中可能承担什么责任，先帮我做个研究提纲和备忘。”

### 推荐处理

1. 先确认：
   - 是上市公司还是非上市公司
   - 关注的是内部治理责任、民事责任还是监管责任
   - 是否需要结合类案
2. 先分别做法规和案例关键词检索；无法可靠拆分或仍有关键缺口时，再升级综合召回。
3. 若草稿中引用明确法条，用 `citation-validator` 核验。
4. 输出：
   - 主要规则
   - 主要案例
   - 初步风险判断
   - 待进一步研究问题

### 最适合的交付形式

- 适合内部研讨的研究备忘
- 也适合作为后续正式法律意见书的前置底稿
