# Governance Research Memo Template

在输出公司治理研究备忘时，优先使用下面的模板。

```markdown
## 研究问题与范围
- 研究问题：[一句话]
- 公司/交易背景：[如有]
- 检索范围：[法域/地区/时间范围]
- 仍待澄清：[如有]

## 主要规则线索
- [法规/规范性文件名称]：[相关要点]（来源：当次 MCP 返回）
- [法规/规范性文件名称]：[相关要点]（来源：当次 MCP 返回）

## 主要案例线索
- [案例名称/案号]：[与本问题相关的要点]（来源：当次 MCP 返回）
- [案例名称/案号]：[与本问题相关的要点]（来源：当次 MCP 返回）

## 初步判断
- 倾向性结论：[在当前样本下的初步判断]
- 反向风险：[可能削弱该判断的因素]
- 样本局限：[地区、年份、样本数量、资料混杂等]

## 待进一步研究的问题
1. [子问题 1]
2. [子问题 2]

## 引用核验结果
- 与当次返回一致：[引用A]
- 待人工复核：[引用B + 原因]

## 链接化版本
- [如已生成 doc-link，则列链接或增强后的文本]

## 使用边界
- 本备忘为研究与讨论辅助，不构成正式律师法律意见。
- 对外沟通或正式意见书仍需结合完整事实与进一步检索复核。
```

## 使用要求

- 先缩小研究问题，再展开检索。
- 规则线索与案例线索分开写。
- 若问题仍过宽，优先列“待进一步研究的问题”。
