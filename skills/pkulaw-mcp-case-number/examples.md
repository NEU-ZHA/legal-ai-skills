# 使用示例

## 示例一：从长文本里识别案号

### 用户输入

```text
请帮我从下面这段客户材料里识别案号，并给我可以继续核查的案件线索。
```

### 推荐行为

1. 这是案号识别与溯源，不是案例检索。
2. 先输出识别到的案号，再输出溯源命中情况。
3. 歧义项只能标“待人工确认”。

### 推荐输出

```markdown
## 识别到的案号列表
- [此处列识别到的案号]

## 溯源命中情况
- [此处列当次返回中的案件线索]

## 待人工确认项
- [此处列格式异常或歧义项]
```

