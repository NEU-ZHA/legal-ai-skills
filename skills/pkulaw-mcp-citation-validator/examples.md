# 使用示例

## 示例一：核验已有答复里的法条引用

### 用户输入

```text
请帮我核验下面这段回复里的法条引用是否准确：
“根据《劳动合同法》第三十九条，公司可以直接解除劳动合同……”
```

### 推荐行为

1. 这是引用核验，不是法规检索。
2. 只根据当次核验返回给出“命中 / 不命中 / 需复核”。
3. 不要把核验结果扩写成新的实体法结论。

### 推荐输出

```markdown
## 原引用
- 《劳动合同法》第三十九条

## 核对状态
- [命中 / 不命中 / 需复核]

## 修正建议
- [此处仅根据当次返回给出修正意见]
```

---

## 示例二：不该用这个 Skill 的情况

### 用户输入

```text
帮我先找一下劳动合同解除相关法律依据。
```

### 推荐行为

这不是引用核验，而是法规检索，应转到法规检索 Skill。

---

## 示例三：结果不明确时

当返回结果不明确时，只允许输出：

```markdown
当前引用核验结果不够明确。

建议：
- 先标记为“需人工复核”
- 如有必要，补做法规检索或精准法条查询
```
