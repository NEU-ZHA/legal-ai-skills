# 使用示例

## 示例一：标准法规依据问题

### 用户输入

```text
员工连续旷工三天，公司能否解除劳动合同？请先帮我找相关法律依据。
```

### 推荐行为

1. 这是法规依据检索问题，不是案例检索问题。
2. 用户给的是自然语言咨询，应优先走 `law-semantic`。
3. 只在语义结果太宽时，再补一次 `law-keyword`。

### 推荐命令

```bash
pkulaw-mcp law-semantic <toolName> --text "员工连续旷工三天 公司能否解除劳动合同 法律依据"
```

### 推荐输出

```markdown
## 问题重述
当前问题聚焦于：员工连续旷工情况下，解除劳动合同可优先关注哪些法规依据。

## 检索路径
- 已优先使用 `law-semantic`

## 关键结果片段
- [此处摘录本次返回中的法规标题、条文片段或摘要]

## 初步观察
从本次检索结果看，可优先关注劳动合同解除条件、规章制度依据与程序要求相关规范。

## 待复核点
- 公司规章制度是否有效制定并公示
- 旷工事实是否有完整证据
```

## 示例二：关键词检索更合适

### 用户输入

```text
帮我查和“劳动合同”“经济补偿金”相关的法规。
```

### 推荐行为

用户已经给了明确关键词，应优先走 `law-keyword`，而不是先走语义。

---

## 示例三：检索失败时

当工具调用失败、无结果或未认证时，只允许输出：

```markdown
当前未拿到法宝法规检索结果。

失败原因：
- [未认证 / 无订阅 / 无结果 / 命令报错]

建议动作：
- 检查 `pkulaw-mcp` 配置
- 更换关键词或缩小问题范围
```

不要在失败后补写“根据一般理解，可能适用某某法律”。
