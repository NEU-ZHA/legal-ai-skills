# 使用示例

## 示例一：标准类案问题

### 用户输入

```text
员工连续旷工三天，公司解除劳动合同有没有类似案例可参考？
```

### 推荐行为

1. 这是案例检索问题，不是法规检索问题。
2. 用户给的是完整争议描述，应优先走 `case-semantic`。
3. 只在语义结果太宽时，再补一次 `case-keyword`。

### 推荐命令

```bash
pkulaw-mcp case-semantic <toolName> --text "员工连续旷工三天 公司解除劳动合同 类似案例"
```

### 推荐输出

```markdown
## 问题重述
当前问题聚焦于：连续旷工解除劳动合同场景下是否存在可参考的类案样本。

## 检索路径
- 已优先使用 `case-semantic`

## 关键案例片段
- [此处摘录本次返回中的案号、法院、裁判摘要]

## 样本观察
从本次检索结果看，法院通常会关注规章制度依据、旷工事实证据和解除程序。

## 待复核点
- 公司规章制度是否明确约定旷工处理
- 证据链是否完整
```

## 示例二：关键词检索更合适

### 用户输入

```text
帮我查“房屋租赁 押金返还 提前解除”相关案例。
```

### 推荐行为

用户已经给了明确争点关键词，应优先走 `case-keyword`。

---

## 示例三：检索失败时

当工具调用失败、无结果或未认证时，只允许输出：

```markdown
当前未拿到法宝案例检索结果。

失败原因：
- [未认证 / 无订阅 / 无结果 / 命令报错]

建议动作：
- 检查 `pkulaw-mcp` 配置
- 更换争点表达或缩小问题范围
```

不要在失败后补写“法院通常会支持谁”之类的推断。
