# Batch Contract Screening Examples

## 示例一：采购合同批量审批前初筛

### 用户意图

“这批采购合同今天要走审批，帮我先把明显风险过一遍，按严重程度排个序。”

### 推荐处理

1. 先确认：
   - 本批合同是否为同模板或近似模板
   - 本次最关注付款、违约、解除还是争议解决
   - 是否存在必须适用的行业规则或公司制度
2. 按合同类型或模板版本分组，不要把全部文本混成一次结论。
3. 用 `law-recognition` 识别各合同里的法规引用与依据线索。
4. 用 `citation-validator` 核验引用是否准确、一致。
5. 输出“批次概览 + 风险台账 + 整改优先级”。

### 最适合的交付形式

- 先给红/黄/绿分布
- 再给条款类型维度的风险台账
- 最后一段给审批人看的简短摘要

## 示例二：旧模板批量换法依据

### 用户意图

“这批旧合同模板可能还沿用了老表述，帮我快速看看哪些条款的依据需要更新。”

### 推荐处理

1. 重点关注：
   - 依据条款
   - 违约责任
   - 解除条件
   - 争议解决
2. 先按条款类型聚类，再逐类检查，不要逐份散着看。
3. 用 `law-recognition` 找出旧法引用或模糊法规表述。
4. 用 `citation-validator` 检查引用表述与当次返回是否一致。
5. 把结果归成：
   - 引用错误
   - 引用过时
   - 适用条件不清
   - 建议替换表述

### 不要这样做

- 不要把“系统未命中”写成“没有风险”
- 不要把“低风险”理解成“可以跳过律师复核”
- 不要在没有核验依据的情况下直接说“条款合法有效”
