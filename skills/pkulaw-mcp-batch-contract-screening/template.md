# Batch Contract Screening Template

在输出批量合同初筛结果时，优先使用下面的风险台账模板。

```markdown
## 批次概览
- 合同批次：[名称/编号]
- 合同总数：[n]
- 红/黄/绿/待人工复核：[n]/[n]/[n]/[n]

## 风险台账（按条款类型）
### 违约责任
1. 合同：[编号]
   - 风险等级：[红/黄/绿/待人工复核]
   - 问题类型：[引用错误/依据缺失/表述歧义/适用条件不明]
   - 条款摘要：[1句话]
   - 核验结果：[与当次返回一致/待核验/存在偏差]
   - 建议动作：[修订/补充依据/律师复核]

### 解除条款
1. 合同：[编号]
   - 风险等级：[红/黄/绿/待人工复核]
   - 问题类型：[引用错误/依据缺失/表述歧义/适用条件不明]
   - 条款摘要：[1句话]
   - 核验结果：[与当次返回一致/待核验/存在偏差]
   - 建议动作：[修订/补充依据/律师复核]

## 整改优先级
1. 需立即处理：[红色项]
2. 建议本周处理：[黄色项]
3. 可例行复核：[绿色项]

## 使用边界
- 本台账为批量合规初筛与技术核对辅助，不构成正式法律意见或尽职调查结论。
- 红色、黄色与待人工复核项应由执业律师或负责人员结合交易背景再次确认。
```

## 使用要求

- 红色项必须附问题说明与建议动作。
- 若系统未命中，不要直接写成“无风险”。
- 若用户只要摘要，可保留“批次概览 + 整改优先级”两部分。
