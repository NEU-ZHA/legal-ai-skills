# Regulatory Reply Check Template

在输出监管回复函或说明材料的依据核查底稿时，优先使用下面的模板。

```markdown
## 核查范围
- 文档类型：[监管回复函/客户回复函/说明材料/审批说明]
- 核查对象：[全文/重点段落/引用清单]
- 重点核查部分：[如有]

## 核查结果概览
- 与当次返回一致：[n]项
- 待人工复核：[n]项
- 需修正后再引用：[n]项

## 核查台账
1. 引用位置：[章节/段落/脚注]
   - 当前引用：[法规名 + 条号/表述]
   - 核查结果：[与当次返回一致/待人工复核/需修正]
   - 回源依据：[fatiao / citation-validator 返回要点]
   - 问题说明：[简称不清/表述偏差/条号不稳/未回源]
   - 建议动作：[保留/修改/补回源/删除后重写]

## 关键条文回源记录
- [法规名 + 条号]：[已回源 / 待回源]
- [如已回源，摘录与当前结论直接相关的原文要点]

## 出具前提示
- 可继续保留的引用：[要点]
- 必须修正或补充依据的引用：[要点]
- 仍需承办律师/负责人员确认的事项：[要点]

## 使用边界
- 本结果为依据核对与技术一致性辅助，不构成正式法律意见。
- 对外发送前，请由负责人员结合完整事实和监管语境再次复核。
```

## 使用要求

- 先确认核查范围，再逐条核查。
- 每个“与当次返回一致”结论都要能回到当次工具返回。
- 对影响核心结论的条文，优先回源。
