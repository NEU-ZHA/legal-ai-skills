# Optional Reference Data

This public package intentionally does not redistribute third-party citation handbook PDFs, OCR text, or full derived rule indexes.

For full coverage, place legally obtained local files in this directory:

- `citation_rules.json`
- `handbook_rule_index.json`
- `handbook_rule_index.md`

Without those files, the skill can still diagnose citation type, identify missing elements, and produce placeholder-safe guidance, but exhaustive handbook verification is unavailable.
