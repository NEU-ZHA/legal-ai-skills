# Case Memo Template

在输出类案备忘时，优先使用下面的模板。

```markdown
## 检索目标
- 争议问题：[一句话]
- 预期用途：[内部讨论/客户沟通/庭前准备]
- 检索范围：[地区/法院层级/时间范围，如有]

## 核心类案（Top N）
1. [案例名称/案号]
   - 相关性理由：[1句话]
   - 裁判要点：[1-2条]
   - 适用边界：[1句话]

## 案号核验结果
- 已核验：[列表]
- 待复核：[列表 + 原因]

## 实务提示
- 对当前方案有利的线索：[要点]
- 可能不利的线索：[要点]
- 样本局限：[样本数量、地区偏差、时间偏差等]

## 链接化备忘
- [如已生成 doc-link，则列链接或增强后的文本]

## 使用边界
- 本备忘为办案与研究辅助，不构成胜诉预测或正式律师法律意见。
- 对客户、法院或正式文书的最终表述须由承办律师结合完整案情审定。
```

## 使用要求

- 至少保留 2-3 个真正相关的样本，不要只追求数量。
- 每个“有利点/不利点”都要能回到具体案例样本。
- 如样本不足，必须把“样本局限”写出来。
