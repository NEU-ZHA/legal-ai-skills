# Case Memo Examples

## 示例一：劳动争议庭前备忘

### 用户意图

“员工主张公司违法解除，我们想看近几年类似案件法院怎么判，帮我做个庭前备忘。”

### 推荐处理

1. 先问：
   - 解除原因是什么
   - 想支持哪一方立场
   - 是否限定地区和法院层级
   - 是否要近三年样本
2. 用 `case-semantic` 或 `case-keyword` 检索。
3. 选出最相关样本，不要只堆列表。
4. 用 `case-number` 核关键案号。
5. 输出“有利点 / 不利点 / 样本局限”。

### 最适合的交付形式

- Top 3-5 个核心类案
- 每个类案给一句“为什么相关”
- 单列样本局限，避免误导为“普遍裁判规则”

## 示例二：给客户的类案沟通材料

### 用户意图

“客户想知道类似供应商违约的案子一般怎么处理，给我一版能沟通的材料。”

### 推荐处理

1. 先确定要不要写具体胜诉预估；若用户想要，明确只能给趋势线索，不能给结果承诺。
2. 检索供应合同违约、解除、赔偿责任相关类案。
3. 输出“可沟通版本”，重点保留：
   - 核心样本
   - 倾向性线索
   - 不确定因素
4. 若要转发客户，再补 `doc-link`。

### 不要这样做

- 不要把“找到多个支持样本”写成“法院一贯支持”
- 不要忽略地区、年份、事实差异
