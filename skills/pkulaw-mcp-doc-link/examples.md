# 使用示例

## 示例一：给已有答复补法宝链接

### 用户输入

```text
请把这份法律答复里的法规引用都补成可点击的法宝链接。
```

### 推荐行为

1. 这是超链增强，不是法规检索。
2. 输出增强后正文，并单列链接命中摘要。
3. 对未命中项只给改写建议，不手工拼接链接。

### 推荐输出

```markdown
## 增强后正文
[此处放链接增强后的正文]

## 链接命中摘要
- [此处列已命中的引用]

## 未命中项
- [此处列未命中的引用]
```

## 示例二：不该用这个 Skill 的情况

### 用户输入

```text
帮我找劳动合同解除相关法规。
```

### 推荐行为

这不是超链增强，而是法规检索，应先转到法规检索 Skill。
