# Opinion Citation Check Examples

## 示例一：法律意见书签发前总复核

### 用户意图

“这份法律意见书今晚要签发，帮我把里面引用的法条先核一遍，重点看结论部分。”

### 推荐处理

1. 先问：
   - 是核全文还是只核结论段落、脚注和附件引用
   - 哪些结论属于必须优先核验的高风险部分
   - 是否已有单独整理好的引用清单
2. 先提取重点引用，不要一上来做泛泛法规检索。
3. 用 `citation-validator` 逐条核对引用表述。
4. 对影响核心结论的条文，用 `fatiao` 回源原文。
5. 输出“与当次返回一致 / 待人工复核 / 需修正后再引用”的核验底稿。

### 最适合的交付形式

- 先给核验结果概览
- 再给逐条核验台账
- 最后一段单列“签发前提示”

## 示例二：客户回复函中的重点条文把关

### 用户意图

“客户回复函里引用了几条监管规定，先帮我确认这些条号和表述有没有问题。”

### 推荐处理

1. 先确认：
   - 只核客户回复函里的引用，还是连同附件说明一起核
   - 哪些条文会直接影响最终回复口径
   - 是否有引用密集段落可直接提供
2. 优先处理重点条文，不要把范围扩大成整篇法规研究。
3. 用 `citation-validator` 先做一致性核验。
4. 对关键条号再用 `fatiao` 回源确认原文。
5. 输出可直接交给承办律师复核的核验表。

### 不要这样做

- 不要把“与当次返回一致”写成“法律意见正确”
- 不要在没锁定重点段落前，直接扩写为全面法规分析
