# Opinion Citation Check Template

在输出法律意见书引用核验底稿时，优先使用下面的模板。

```markdown
## 核验范围
- 文档类型：[法律意见书/法律备忘/合规结论/回复函]
- 核验对象：[全文/重点段落/引用清单]
- 重点结论或段落：[如有]

## 核验结果概览
- 与当次返回一致：[n]项
- 待人工复核：[n]项
- 需修正后再引用：[n]项

## 核验台账
1. 引用位置：[章节/段落/脚注]
   - 当前引用：[法规名 + 条号/表述]
   - 核验结果：[与当次返回一致/待人工复核/需修正]
   - 当次依据：[citation-validator 或 fatiao 返回的关键内容]
   - 问题说明：[简称不清/条号不稳/表述偏差/回源未命中]
   - 建议动作：[保留/补回源/修改表述/删除后重写]

## 关键条文回源
- [法规名 + 条号]：[已回源 / 待回源]
- [如已回源，摘录与当前结论直接相关的原文要点]

## 签发前提示
- 可继续保留的引用：[要点]
- 必须修正或复核的引用：[要点]
- 仍需承办律师确认的事项：[要点]

## 使用边界
- 本结果为引用核对与技术一致性辅助，不构成正式法律意见或签章结论。
- “与当次返回一致”不等于已完成实体法律审查，签发前仍须由承办律师复核。
```

## 使用要求

- 先确认核验范围和重点段落，再开始逐条核验。
- 每个“与当次返回一致”结论都要能回到当次工具返回。
- 对影响核心结论的条文，尽量至少完成一次 `fatiao` 回源。
