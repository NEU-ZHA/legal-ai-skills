# Labor Employment Answer Examples

## 示例一：绩效不达标能否解除

### 用户意图

“员工连续两个月绩效不达标，公司能不能直接辞退？帮我整理一个给业务的回复口径。”

### 推荐处理

1. 先问：
   - 员工所在地
   - 绩效制度是否书面公示
   - 是否有考核记录与改进过程
   - 是否需要类案
2. 用法规检索 Skill `pkulaw-mcp-law-retrieval` 检索解除劳动合同、绩效管理相关规则。
3. 如需裁判倾向，补案例检索 Skill `pkulaw-mcp-case-retrieval`。
4. 草稿里出现具体法条时，用 `citation-validator` 核验。
5. 输出“简要结论 + 主要依据 + 风险提示”的回复草稿。

### 不要这样做

- 不要直接写“可以辞退”
- 不要忽略绩效制度、公示、考核程序这些事实前提

## 示例二：未签劳动合同争议

### 用户意图

“业务问：员工已经入职但一直没签劳动合同，现在补签还来得及吗？帮我回复一下。”

### 推荐处理

1. 先确认：
   - 入职时间
   - 是否已有工资发放、考勤或社保记录
   - 目前是否仍在职
2. 用法规检索 Skill `pkulaw-mcp-law-retrieval` 检索未签劳动合同、双倍工资责任相关规则。
3. 如需看裁判风险，再补案例检索 Skill `pkulaw-mcp-case-retrieval`。
4. 输出：
   - 当前法律风险
   - 可以立即采取的动作
   - 不宜直接承诺的点

### 最适合的交付形式

- 给业务：短结论先行
- 给法务：附依据和待补事实
