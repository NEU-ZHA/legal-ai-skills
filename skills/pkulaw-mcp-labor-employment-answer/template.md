# Labor Employment Answer Template

在输出劳动用工答复草稿时，优先使用下面的模板。

```markdown
## 问题与适用前提
- 问题：[一句话概括]
- 地区/法域：[如有]
- 当前已知事实：[制度、公示、通知、证据等]
- 仍待补充：[如有]

## 简要结论
1. [结论 1，避免绝对化措辞]
2. [结论 2]

## 主要依据
- [法规/司法解释名称]：[与本问题相关的要点]（来源：当次 MCP 返回）
- [案例名称/案号]：[如需类案支撑]（来源：当次 MCP 返回）

## 风险提示
- 对公司/业务方的主要风险：[要点]
- 对员工主张可能成立的点：[要点]
- 当前事实不足导致无法下结论的点：[要点]

## 引用核验结果
- 与当次返回一致：[引用A]
- 待人工复核：[引用B + 原因]

## 可转发版本
- [如已生成 doc-link，则列链接或增强后的文本]

## 使用边界
- 本答复为研究与沟通辅助草稿，不构成正式律师法律意见。
- 对外发送前，请由承办律师或负责人员结合完整事实再次复核。
```

## 使用要求

- 先写事实前提，再写结论。
- 结论必须与依据一一对应。
- 没有核验的具体法条，不要写成确定依据。
