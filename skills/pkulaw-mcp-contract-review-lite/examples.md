# Contract Review Lite Examples

## 示例一：采购合同审批前初筛

### 用户意图

“帮我看这份采购合同，有没有明显风险，今天要走审批。”

### 推荐处理

1. 先问：
   - 采购的是货物还是服务
   - 审查重点是付款、违约还是争议解决
   - 是否有必须适用的行业监管规则
2. 按重点模块拆分合同。
3. 用 `law-recognition` 找条款里的法规引用。
4. 用 `fatiao` 回源关键条号。
5. 用 `citation-validator` 检查引用表述是否偏差。
6. 输出风险台账，而不是只给一段总评。

### 最适合的交付形式

- 高风险 / 中风险 / 待人工复核
- 每条附“建议动作”
- 最后一段给审批人看的简短摘要

## 示例二：旧版模板依据更新

### 用户意图

“这是旧模板，里面很多条款可能还是按合同法写的，帮我快速过一遍。”

### 推荐处理

1. 重点检查“依据条款”“争议解决”“违约责任”“解除条款”。
2. 识别旧法引用，特别关注已废止或已被新法吸收调整的条款。
3. 回源新法对应条文。
4. 把问题集中归成：
   - 引用错误
   - 引用过时
   - 适用条件不清
   - 建议替换表述

### 不要这样做

- 不要把“低风险”理解成“可以跳过律师复核”
- 不要在没有回源的情况下直接说“条款合法有效”
