# Contract Review Lite Template

在输出合同初筛结果时，优先使用下面的风险台账模板。

```markdown
## 初筛范围
- 合同类型：[采购/销售/服务/其他]
- 审查目的：[签约前/审批前/模板迭代/存量排查]
- 审查重点：[付款/违约/解除/保密/争议解决/其他]

## 风险概览
- 高风险：[n]项
- 中风险：[n]项
- 低风险：[n]项
- 待人工复核：[n]项

## 风险台账
1. 条款位置：[章节/条款号]
   - 风险等级：[高/中/低/待人工复核]
   - 问题类型：[引用错误/依据缺失/表述冲突/适用条件不明]
   - 条款摘要：[1句话]
   - 检索/回源依据：[对应法规或条号]
   - 核验结果：[与当次返回一致/待核验/存在偏差]
   - 建议动作：[修订/补充定义/删除/律师复核]

## 优先处理建议
1. 需立即处理：[高风险项]
2. 可在定稿前处理：[中风险项]
3. 例行复核即可：[低风险项]

## 使用边界
- 本结果为合同合规初筛，不构成正式法律意见。
- 高风险项与待人工复核项应由执业律师或负责人员结合交易背景再次确认。
```

## 使用要求

- 每个高风险项都要带依据。
- 若条款没有足够检索依据，不要给确定性结论。
- 若用户只要摘要，可保留“风险概览 + 优先处理建议”两部分。
