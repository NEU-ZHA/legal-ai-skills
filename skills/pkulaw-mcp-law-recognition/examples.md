# 使用示例

## 示例一：从合同条款中识别法规引用

### 用户输入

```text
请识别下面这段合同条款里提到的法规和条号，并给我可继续核查的线索。
```

### 推荐行为

1. 这是识别已有文本中的法规引用。
2. 只输出识别结果、溯源线索和置信提示。
3. 不要直接扩写成“该法条一定适用”。

### 推荐输出

```markdown
## 识别结果
- [此处列识别到的法规名与条号]

## 溯源线索
- [此处列当次返回中的来源字段]

## 置信提示
- [高 / 中 / 低]

## 待人工复核项
- [此处列歧义项]
```

## 示例二：不该用这个 Skill 的情况

### 用户输入

```text
帮我找劳动合同解除相关法规。
```

### 推荐行为

这不是从现有文本里识别法规引用，而是法规检索，应转到法规检索 Skill。
