# 法学引注手册本地配置说明 / Local Citation Handbook Setup

这个文件给课堂分享、同学互助和本地安装使用。仓库不携带《法学引注手册（第二版）》PDF、OCR 全文或完整规则索引；每个使用者应把自己合法取得的同版文件放到本地，再生成机器可读索引。

## 一分钟版

1. 安装本仓库的 skills。
2. 准备同版《法学引注手册（第二版）》PDF。
3. 如果 PDF 不能选中文字，先用 WPS、Adobe Acrobat 或 OCR 工具转成可搜索 PDF。
4. 把 PDF 放到：

```text
skills/legal-citation-comprehensive/assets/Law_Journal_Citation_Handbook_2025.pdf
```

5. 运行自动构建脚本：

```bash
python3 skills/legal-citation-comprehensive/scripts/build_reference_data.py
```

它会自动检查 PDF 是否可搜索、提取文本、抽取 1-150 条规则、生成本地参考文件，并继续跑审计和测试。已有参考文件时默认不覆盖；确认重建再加 `--force`。

6. 成功后会得到下面这些本地文件：

```text
skills/legal-citation-comprehensive/references/handbook_raw.md
skills/legal-citation-comprehensive/references/citation_handbook_structured.md
skills/legal-citation-comprehensive/references/handbook_rule_index.json
skills/legal-citation-comprehensive/references/handbook_rule_index.md
skills/legal-citation-comprehensive/references/citation_rules.json
```

7. 如果想手动复核，可以再跑：

```bash
python3 skills/legal-citation-comprehensive/scripts/audit_reference_data.py
python3 skills/legal-citation-comprehensive/scripts/handbook_lookup.py --rule 1
python3 skills/legal-citation-comprehensive/scripts/self_test.py
```

请先运行：

如果脚本提示 PDF 不可搜索，请先停止，提醒我用 WPS/Adobe/OCR 工具转成可搜索 PDF；不要直接全文 OCR 整本扫描件来浪费 token。

如果脚本提示规则抽取不完整，请运行：

然后严格按 contract 修复本地参考数据。

目标是生成：

- types

OCR 不清楚的地方标记为 [待核: OCR]。
生成后运行：

## 分享时怎么说

可以这样讲：

```text
这个 skill 本身不把《法学引注手册》打包进去。你需要自己准备同版 PDF；如果是扫描版，先用 WPS 转成可搜索 PDF。然后把 PDF 放进指定目录，运行 build_reference_data.py。脚本会生成 5 个本地参考文件，并自动跑 audit_reference_data.py 和 self_test.py；两个都通过，才可以说完成完整手册规则核验。没生成之前，也可以先做脚注类型判断、缺项提示和占位符安全建议。
```

## 常见错误

- 只有 PDF，没有索引：先跑 `build_reference_data.py`；没通过前只能做初步诊断，不能声称已经完成手册全量核验。
- 扫描 PDF 直接丢给 AI：token 消耗大，OCR 错误多。先转可搜索 PDF。
- 规则号缺漏：`audit_reference_data.py` 或 `self_test.py` 会失败。不要忽略。
- 结构像是生成了但质量不稳：先跑 `audit_reference_data.py`。有 ERRORS 就返工。
- OCR 不清楚却直接补写：必须标 `[待核: OCR]`。
- 缺出版社、年份、页码、案号：用 `[待补: ...]`，不要猜。
